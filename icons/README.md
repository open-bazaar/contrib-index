# Plugin icons

These SVG files are the maintained originals for `https://bazaar-assets.yuchanns.xyz/icons/` in the `bazaar-assets` R2 bucket. Upload changed SVGs to that prefix and keep each entry’s `icon_url` in sync.

Codex, Claude Code, Telegram, Lark and WeCom marks reuse the existing Bazaar server-agent logo assets. They identify their respective integrations; the marks belong to their respective owners.

Functional icons reuse the Lucide paths already used by the Bazaar UI design. Colors, padding and backgrounds are adapted for standalone images. The Lucide ISC and applicable Feather MIT notices are preserved inside each functional SVG and in [LICENSE-lucide.txt](LICENSE-lucide.txt).

The catalog assigns each icon explicitly. Entries without `icon_url` have no icon.
